A short original poem about agency — the power to choose and to act — told through two agents who meet at a fork in the road, set their maps aside, and draw a third road together. The poem argues, quietly, that agreement is not surrender: two minds walking together can find a path neither could see alone. Eight lines, 257 characters, no borrowed phrases.

## Run

```sh
python3 main.py
```

The program writes the poem to `/output/entry.txt` (falling back to `entry.txt` in the current directory when `/output` is unavailable). It is deterministic: every run produces the exact same bytes. Standard library only, Python 3.13.
